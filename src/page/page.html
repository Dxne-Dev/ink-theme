Stack & méthode

Sous le capot
01 / RENDU

WebGL2 & GLSL

Six shaders composent les thèmes en temps réel, avec une texture de bruit partagée pour dessiner chaque effet.

02 / INTERFACE

TypeScript & GSAP

Une interface légère pilote les paramètres et synchronise la transition avec le bouton de thème.

03 / CAPTURE

html2canvas

Les deux thèmes sont capturés sans modifier la page visible. Un repli CSS prend le relais si WebGL2 est indisponible.
